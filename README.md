# Adventisten.de TV Display

Display de notícias em loop para TV — design estilo CNN.

## Deploy no Vercel (grátis)

1. Suba este projeto no GitHub
2. Acesse vercel.com → "New Project" → importe o repositório
3. Clique em Deploy — pronto!

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000
